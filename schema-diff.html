使い方と注意事項

基本操作

  1. Beforeに比較元のParquet / CSV / TSV / JSONL / NDJSONを追加します。
  2. Afterに比較先のファイルを追加します。
  3. 推定形式は必要に応じて行数設定を調整し、「スキーマを比較」で変更を確認します。

プライバシー

ファイルはブラウザー内だけで処理し、外部サーバーへ送信しません。Parquetのスキーマは末尾のメタデータ領域から読み、先頭10行プレビューを開いた場合だけ必要な行データを追加で読みます。CSV / TSV / JSONL / NDJSONも必要な範囲だけを読みます。

注意事項

  • CSV / TSV / JSONL / NDJSONの型やNULL情報はデータからの推定です。明示的な制約ではありません。
  • Parquet / CSV / TSV / JSONL / NDJSONは形式をまたいで比較できます。形式固有の型表現は共通型へ正規化して判定します。
  • 壊れたファイルや推定範囲外にだけ存在する値は正しく判定できない場合があります。
  • CSV / TSVの重複・空欄ヘッダーには、明示された列名と重ならない名前を割り当てます。
  • スキーマやプレビューの読み込み中は入れ替えできません。読み込み終了後に利用できます。
  • 「名前変更」は両側で一意なField IDが一致するParquetの名前変更に絞り込みます。変更前・変更後のパスで検索できます。
  • 検索とフィルターは画面表示だけに適用されます。コピー、Markdown、JSONには比較結果全体を出力します。

単一HTMLとしてローカルで直接開いて利用できます。
